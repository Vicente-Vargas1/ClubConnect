1️⃣ Node.js – JavaScript on the server

What it is: A runtime that lets you run JavaScript outside the browser.
Role: Backend. Handles requests, talks to the database, sends data back to the frontend.
Analogy: Think of it as the kitchen in a restaurant. You don’t see it, but all the cooking (logic, data handling) happens here.

2️⃣ Express – Web framework for Node.js

What it is: A framework/library built on Node.js that makes it easier to handle web requests and routes.
Role: Backend. Defines API endpoints, like /login or /messages.
Analogy: The recipes and workflow in the kitchen — it organizes how things are cooked and served.

3️⃣ React.js – Frontend library

What it is: A JavaScript library for building user interfaces.
Role: Frontend. Manages what users see and interact with in their browser.
Analogy: The dining room and waiter — what the customer sees, where they interact, how the food (data) is presented.

4️⃣ MongoDB – Database

What it is: A NoSQL database that stores data in JSON-like documents.
Role: Backend. Keeps your data persistent: users, chat messages, posts, etc.
Analogy: The pantry or storage room in the restaurant — all ingredients (data) are stored here until needed.
